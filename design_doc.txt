1. Project Overview
1.1 What This Is
A single-page personal portfolio website for a Full-Stack Software Engineer with an AI/ML focus. One page. Sticky navbar. Anchor-scroll between sections. Dark theme by default with a light theme toggle.

1.2 Goals (priority order)
Get the owner hired or contacted — recruiters must evaluate skills, see projects, and reach out within 30 seconds.

Showcase full-stack depth and AI/ML interest — the site itself should feel like a well-engineered artifact.

Establish personal brand — confident, modern, understated, technical.

1.3 Audience
Technical recruiters (skim-first, mobile-heavy)

Engineering managers / tech leads (evaluate depth, click GitHub)

Peers and collaborators (network, open source)

1.4 Success Criteria
Lighthouse ≥ 95 on Performance, Accessibility, Best Practices, SEO (desktop + mobile).

All primary content reachable within one scroll or one click.

CLS < 0.1; all motion respects prefers-reduced-motion.

No horizontal scroll between 320px and 1920px.

1.5 Scope
In: Navbar, Hero, About, Skills, Projects, Experience, Contact, Footer. Theme toggle. Scroll animations. Responsive layout.
Out: Routing, backend, contact form submission, CMS, admin panel, blog, analytics, cookies, auth, i18n.

1.6 Stack
React 18+ (function components + hooks only), Vite, TypeScript (strict), Tailwind CSS, Framer Motion (reveals only). No router. No UI component library. Icons as inline SVG only.

5. Design System
5.1 Brand Personality
Modern, technical, understated. Dark-first. High contrast, generous whitespace, a single confident accent. Reads as "well-engineered tools," not "creative agency."

5.2 Color Tokens
Define as CSS custom properties on :root (dark default) and [data-theme="light"] in src/index.css. Map into tailwind.config.ts.

Dark (default):

Token	Hex	Usage
--bg	#0B0E14	Page background (deep blue-black, not pure black)
--bg-elevated	#11151F	Cards, navbar
--border	#232A38	Dividers, card borders
--text-primary	#E6EAF2	Headings, body
--text-secondary	#9AA4B8	Subtext, labels
--accent	#5EEAD4	CTAs, links, highlights
--accent-strong	#2DD4BF	Hover states
--accent-contrast	#04231F	Text on accent buttons
--glow	rgba(94, 234, 212, 0.15)	Focus glows, hero motif
Light:

Token	Hex
--bg	#F8FAFC
--bg-elevated	#FFFFFF
--border	#E2E8F0
--text-primary	#0F172A
--text-secondary	#475569
--accent	#0D9488
--accent-strong	#0F766E
--accent-contrast	#FFFFFF
Rules: No pure #000/#FFF in dark mode. Accent used sparingly — CTAs, active nav, link underlines, small decor. Never for long body text. Verify AA contrast for every text/background pair.

5.3 Typography
Role	Font	Weight	Size (desktop / mobile)	Line-height
H1	Space Grotesk	600	56 / 36 px	1.1
H2	Space Grotesk	600	36 / 28 px	1.2
H3	Space Grotesk	600	22 / 20 px	1.3
Body	Inter	400	17 / 16 px	1.65
Label	Inter	500	13 px, uppercase, letter-spacing 0.08em	1.4
Mono / chips	JetBrains Mono	400	13 px	1.4
Self-host the three fonts as woff2 in public/fonts/ and load via @font-face with font-display: swap. (No next/font — this is React + Vite.) Preload the H1 and body weights.

Max paragraph width 68ch.

Section label style: uppercase, accent color, letter-spacing 0.12em, preceded by a 24px accent rule line.

5.4 Spacing
8px base scale: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128.

Section vertical padding: 96px desktop / 64px mobile.

Container max-width 1120px, horizontal padding 24px mobile / 40px desktop, centered.

5.5 Radius & Elevation
Radius: 12px cards, 8px buttons/inputs, 999px chips and pills.

Card (dark): background: var(--bg-elevated), border: 1px solid var(--border), inset 0 1px 0 rgba(255,255,255,0.03).

Card hover: translateY(-4px), border accent-tinted 40%, box-shadow: 0 12px 32px rgba(0,0,0,0.35).

5.6 Motion
Easing: cubic-bezier(0.22, 1, 0.36, 1).

Durations: hover 150ms, reveal 500ms, stagger step 80ms.

Scroll reveals: fade + translateY(16px) → 0, triggered once at 15% visibility (Framer Motion whileInView, viewport={{ once: true, amount: 0.15 }}).

prefers-reduced-motion: reduce → disable all transforms, glow pulses, and smooth scroll.

6. Component Specifications
Each component receives its data from site-content.ts. Each is a self-contained function component.

6.1 <Navbar />
Sticky top, 64px tall, backdrop-filter: blur(12px), background color-mix(in srgb, var(--bg) 80%, transparent). A 1px bottom border appears only after 24px of scroll (track with window.scrollY).

Left: wordmark Alex Rivera· (accent dot), Space Grotesk 600.

Center/right (≥768px): nav.links items. Active link (via scroll-spy) is accent-colored with an underline pill.

Right: theme toggle (sun/moon icon, 40×40 hit area, aria-label="Toggle theme", aria-pressed={isDark}), Résumé outline pill.

Mobile (<768px): hamburger button opens a full-width dropdown panel below the navbar. Tap targets ≥48px. Closes on link tap or Esc. Traps focus while open. Returns focus to trigger on close. aria-expanded reflects state.

6.2 <Hero />
min-height: calc(100vh - 64px), content vertically centered, left-aligned in the container.

Order: eyebrow label → H1 → subtext (secondary, ≤60ch) → CTA row: primary (accent-filled pill), secondary (outline pill), tertiary (text link with ↓).

Background motif (≥768px only): soft radial --glow behind an abstract node-graph SVG on the right. Dots + connecting lines, opacity ~0.25, 8s pulse on 3 nodes (disabled under reduced motion). On mobile: hide the graph; keep a faint top-right glow.

Bottom-center thin animated chevron scroll indicator; hidden on mobile.

6.3 <About />
Desktop: 2-column grid 1fr 1.4fr, gap 64px. Left: avatar (160px circular, accent ring at 30% opacity). Right: heading, two paragraphs, quick-facts list.

Avatar: <img src="/avatar.jpg" onError={fallback to initials}> — if image fails, render a circle with avatarInitials in Space Grotesk, secondary color.

Quick facts: stacked rows, --bg-elevated bg, border, radius 8px, padding 10px 14px, 8px gap.

Mobile: single column, avatar centered above text.

6.4 <Skills />
Heading row, then the groups array. Each group: label (small uppercase secondary) above a wrapping flex row of <Chip />s.

Chip: JetBrains Mono 13px, padding 6px 12px, radius 999px, --bg-elevated, --border, --text-primary. Hover: accent-tinted border only (chips are not links).

Desktop: 2-column grid (repeat(2, 1fr), gap 40px 64px). Any group with spanTwoColumns: true spans both columns. Mobile: single column.

6.5 <Projects />
CSS grid repeat(2, 1fr), gap 24px. Featured project spans both columns and uses a horizontal layout on desktop (image 45% left, content right). On mobile, featured stacks vertically like a standard card.

Standard card: image top (16:9), content below with padding 24px: title + subtitle, description (secondary, 3-line clamp with ellipsis), tag chips (non-interactive), link row at bottom.

Featured card shows a small FEATURED accent chip at the top-left of the content area.

Link style: text + ↗ arrow icon, accent color.

Card link integrity: the whole card surface is clickable via the first primary: true link using the stretched-link pattern (absolute inset-0 anchor with aria-label). Any secondary links sit above with position: relative; z-index: 1. No nested <a> elements.

Image placeholder: if /projects/<slug>.png is missing (onError), render a gradient placeholder (linear-gradient(135deg, #1a2233, #0f1420) dark / light equivalent) with the project's initial (Space Grotesk 48px, secondary color) centered.

Card hover: translateY(-4px), border accent-tinted 40%, deeper shadow.

6.6 <Experience />
Vertical timeline: 2px left rail (--border), 10px accent dot marker at each entry, with a subtle ring.

Entry content: role (<h3>), company + dates row (company primary, dates secondary mono), location line (secondary small), bullet list with accent dash markers, 1.65 line-height, secondary text.

Desktop: 3-column grid — dot column | content | dates column (140px, right-aligned). Mobile: single column, rail at 16px, dates below company.

6.7 <Contact />
Full-width panel inside the container: --bg-elevated background, radius 16px, border, padding 64px desktop / 32px mobile, corner accent radial glow.

Layout: copy + primary Email me accent button; secondary social links (icon + label) in a horizontal row. Desktop: may split into 2 columns (copy left | links right). Mobile: stacked.

Email me uses <a href={contact.primaryCta.href}> (mailto).

6.8 <Footer />
Top border, padding 40px 0, flex row: copyright (secondary small) left; social icons (GitHub, LinkedIn, X, Email — 24px, secondary → accent hover) and Back to top ↑ right.

copyrightTemplate renders with {year} replaced by new Date().getFullYear().

Back to top scrolls to #hero via href="#hero".

Mobile: vertical stack, centered.

6.9 Shared primitives
<Button variant="primary" | "secondary" | "ghost" /> — pill shape, correct colors per tokens.

<Chip /> — used for skills and project tags.

<SectionLabel label="..." /> — rule line + uppercase accent label.

<Reveal> — Framer Motion whileInView fade + up wrapper; disabled if prefers-reduced-motion.

7. Interaction & State
Theme:

Default dark. data-theme="dark" set on <html> in index.html.

Toggle in Navbar updates document.documentElement.dataset.theme, writes localStorage['theme'], reflects aria-pressed.

On first load, read localStorage['theme']; if absent, use prefers-color-scheme. Prevent flash with an inline <script> in index.html <head> that sets data-theme before React mounts.

Scroll-spy: IntersectionObserver with rootMargin: "-40% 0px -55% 0px"; update active nav link.

Smooth scroll: html { scroll-behavior: smooth }. All section IDs have scroll-margin-top: 80px to offset the sticky navbar. Disabled under reduced motion.

Focus: :focus-visible → 2px solid var(--accent), outline-offset: 3px, box-shadow: 0 0 0 6px var(--glow).

External links open in new tab with rel="noopener noreferrer" and aria-label noting "opens in new tab" where not obvious.

Reduced motion: no reveals, no glow pulse, no smooth scroll. Detected via window.matchMedia('(prefers-reduced-motion: reduce)').

9. Accessibility (WCAG 2.1 AA)
Landmarks: <header>, <nav>, <main>, <section aria-labelledby>, <footer>.

One <h1> (hero). Sections use <h2>. Card titles use <h3>.

All images have alt; decorative SVGs are aria-hidden="true".

Text contrast ≥ 4.5:1; UI/large text ≥ 3:1 in both themes.

Theme toggle reflects state via aria-pressed.

Mobile menu: aria-expanded toggling, focus trap, Esc closes, focus returns to trigger.

Skip-to-content link as the first focusable element, jumps to #main.

Full keyboard operability in logical order.

prefers-reduced-motion honored everywhere.

10.3 Data Flow
App.tsx imports site-content.ts and passes each section's slice into its component as props (or components import their own slice directly — pick one and be consistent). No global state library. Theme handled via data-theme on <html> + a small hook in Navbar.

10.4 SEO & Meta
<title>Alex Rivera — Full-Stack Software Engineer</title> in index.html.

Meta description = hero subtext (≤160 chars).

Open Graph + Twitter card tags. lang="en" on <html>.

Generate og-image placeholder at /public/og-image.png (accent gradient is fine).

10.5 Performance
Self-host fonts, preload H1/body weights.

All images have explicit width/height (or aspect-ratio CSS) to prevent layout shift.

Lazy-load project images (loading="lazy").

Decorative SVGs inline and small.

No third-party scripts.

10.6 Fallbacks
Missing avatar → initials circle.

Missing project image → gradient + initial placeholder.

# placeholder links → keep as <a href="#"> with a code comment so the owner knows to replace.
